# raceGPS — 20-Milestone Program Plan: From Reconciled Baseline to Shipped Game

**Status:** PROPOSED 2026-09-29. Extends and supersedes `docs/10-milestone-plan.md` (approved 2026-09-23).
**Baseline:** branch `integration/reconciled` (Sprint-2 + showcase + grokbot two-app/rgpack/gates + master installer), 303 tests green.
**Design discipline (ECC loop-design):** every milestone is a servo loop with a **machine-decidable done-criterion**, a **boundary** (what it must NOT do), a **reconciliation anchor** (external/golden reference), and a **retry cap of 3 → escalate to owner**. Judge is always CI/scripts — never the builder. The "done" cell is flipped by the owner.

## Original goals being served (from GAMEPLAY_DESIGN / MARKETING / GARAGEGPS / SIGNAL_CHALLENGES)

1. Real mapped cities as playable worlds (OSM → citypack → UE5, geo-true, 1uu=1cm)
2. Midnight-Club-style arcade street racing (fast, drift-friendly, dramatic)
3. Cruise Sprint checkpoint racing with scoring, medals, leaderboards, ghosts
4. Living streets: traffic, day/night, weather
5. garageGPS car-kit editor (fixed chassis, validated modular parts)
6. Career: achievements, persistence, "one global career"
7. Lightweight multiplayer: cookies identity, WebSocket world, signal challenges, live lobbies
8. Cop-vs-Runner Hot Pursuit
9. Player-facing city compiler ("Cartographer")
10. Shippable: cooked installer, crash reporting, docs

## Program shape

| Phase | Name | Milestones | Exit statement |
|-------|------|-----------|----------------|
| 0 | Green Baseline | M1 | one branch, one build, all gates green |
| I | Drivable World | M2–M5 | "feels real, is a game" |
| II | Living World | M6–M9 | "the city is alive at 60fps" |
| III | Player Systems | M10–M13 | "my car, my career, my sound" |
| IV | Connected | M14–M17 | "many rooms, live rivals" |
| V | Product | M18–M20 | "a friend installs and races" |

**Phase gate rule:** a phase closes only when every milestone gate in it is green AND a full-stack playtest evidence pack (log + screenshots + telemetry) is attached. No phase-skipping.

## Standard milestone gate block (applies to every milestone)

- **Done when:** the listed command(s) exit 0 with the stated assertion. Deterministic, rerunnable.
- **Must NOT:** the listed boundary; violating it is an automatic FAIL even if done-criteria pass (anti-Goodhart).
- **Anchor:** the external reconciliation reference (golden file, pinned hash, measured baseline).
- **Evidence:** artifact path committed under `docs/evidence/m<N>/`.
- **Retry:** 3 failed attempts on the same gate → stop, escalate to owner with the failure diff.

## Phase I — Drivable World

### M2 — Real Roads
Lane-accurate asphalt ribbons from XODR/road graph, road-snapped spawns, lane markings.
- **Done when:** validator asserts every spawn on-road; screenshot pack shows marked asphalt under car at all spawns; `test_cleveland_circuit.py` road-mesh assertions green.
- **Must NOT:** drive-on-terrain fallback paths; hand-placed road meshes.
- **Anchor:** road graph node set === mesh source set (1:1 certificate in evidence).

### M3 — Visual Pass 1
Building material buckets, CARLA material dep repair, sidewalks/curbs/furniture from compiled data.
- **Done when:** screenshot diff vs V15 baseline shows downtown reads as downtown; zero `DefaultMaterial`/checkerboard in play-space capture sweep.
- **Must NOT:** new unlit-black failure modes; broken CC-BY attribution files.
- **Anchor:** V15/V16 hero shots as golden references (perceptual diff threshold recorded).

### M4 — Handling & Input
Chaos tuning pass, Enhanced Input migration, gamepad + wheel/FFB, three presets (Arcade/Simcade/Sim).
- **Done when:** scripted telemetry run: 0–100 km/h, braking distance, lateral-g differ measurably per preset (numbers in evidence); wheel+pedals drive a full lap.
- **Must NOT:** change track geometry to mask handling defects; regress AI lap completion.
- **Anchor:** GAMEPLAY_DESIGN.md target figures (220 km/h, ~4s 0–100).

### M5 — Race Loop Complete
NeonHUD full integration (speed/gear/lap/delta/minimap), start lights, results screen, persisted records, ghost polish.
- **Done when:** unattended `-ClevelandProofFinishR` plus human-path playtest both produce start→finish→results with records persisted to `Saved/`; GATES race row PASS (not PASS_PROVISIONAL).
- **Must NOT:** count NullRHI/ForceFinish proof as a Gate-PASS (finish-r-proof-note is law); leave TEMP Track-B diagnostics in (strip list: eb03b9c).
- **Anchor:** G6 evidence pack + new windowed PASS evidence.

## Phase II — Living World

### M6 — Living Traffic
MassEntity traffic, lane-following AI on road graph, OSM signals, spawn/destroy lifecycle.
- **Done when:** CI perf probe with 20 concurrent traffic vehicles holds 60fps budget; traffic respects signal phases from compiled data.
- **Must NOT:** traffic that blocks checkpoints or spawns inside the racing line envelope.
- **Anchor:** density/lifecycle defaults from GAMEPLAY_DESIGN.md (200m spawn / 250m cull / 20 max).

### M7 — World Atmosphere
Day/night presets (Sunset/Twilight/Midnight already gated) + weather presets + wet-asphalt physics materials.
- **Done when:** same route driven in 4 moods + rain; wet surface measurably reduces grip (telemetry delta in evidence).
- **Must NOT:** regress the moon-directional night floor (the black-screen class is permanently banned).
- **Anchor:** `DayNightCycle` moon model + Frame A contract tests.

### M8 — Runtime Repair
BuildingMeshGenerator schema parity, legacy path removal, LANSessionManager map fix.
- **Done when:** runtime-spawned city hash-matches baked city on the building set; deprecated paths deleted and referenced nowhere (grep proof).
- **Must NOT:** keep dual pipelines "just in case."
- **Anchor:** bake-vs-runtime building inventory diff = 0.

### M9 — Performance Envelope
World Partition streaming, HLOD skylines, shader warmup, CI perf budget gate.
- **Done when:** 60fps at target profile in both cities, measured by CI capture, budget file committed.
- **Must NOT:** perf wins by silently dropping the skyline/lighting toolbox below V15 visual bar.
- **Anchor:** V16 hero shot set + frame-time budget YAML.

## Phase III — Player Systems

### M10 — garageGPS Workshop (raceGPSWorkshop target)
Car-kit editor over fixed proven chassis: modular visual parts, controlled performance presets, validation-before-import (GARAGEGPS_TECH_SPEC).
- **Done when:** Workshop target boots standalone; a kit config validates, builds, and appears in Race app via rgpack round-trip (`pytest tools/rgpack` green).
- **Must NOT:** unconstrained text-to-car generation (locked beta rule); unvalidated parts entering Race.
- **Anchor:** rgpack v1 golden fixture round-trip.

### M11 — Career & Progression
Achievements (10 from design doc), medals, per-route leaderboards, cumulative stats, persistence.
- **Done when:** scripted race sequence unlocks `first_race` + `clean_driver`; `Saved/achievements.json` and leaderboards persist across restart (headless test).
- **Must NOT:** client-authoritative "career" claims that a server would contradict later (shape data for M14).
- **Anchor:** achievement table in GAMEPLAY_DESIGN.md (all 10 implemented or explicitly cut).

### M12 — Onboarding & Accessibility
5-step tutorial, assists (ABS/TC/steering), difficulty presets, remappable controls.
- **Done when:** first-run flow completes headlessly via synthetic input; assist toggles measurably change telemetry (e.g. TC cuts wheelspin events).
- **Must NOT:** tutorial that blocks skip; assists that can't be fully disabled.
- **Anchor:** tutorial step table in GAMEPLAY_DESIGN.md.

### M13 — Audio & Feel
Engine audio by RPM/load, surface SFX, music beds, collision/camera drama (SOUND_DESIGN.md).
- **Done when:** audio smoke gate: engine pitch tracks RPM within tolerance on a scripted run; no missing-sample warnings in log.
- **Must NOT:** ship placeholder silence or hot-loop audio hitches > budget.
- **Anchor:** SOUND_DESIGN.md mix targets.

## Phase IV — Connected

### M14 — Identity & Session Backend
Cookie identity, WebSocket world session, presence, city rooms (PROVIDER_ADAPTERS / UE5_BACKEND_WIRE).
- **Done when:** two headless clients join the same room and see each other's presence + transform updates; reconnect restores identity.
- **Must NOT:** plaintext credentials, unauthenticated room admin actions.
- **Anchor:** MARKETING.md architecture line: "Cookies handle identity. WebSockets handle the world."

### M15 — Signal Challenges
Flash→sprint, rev→drag, drop-pin route, ghost signal (SIGNAL_CHALLENGES).
- **Done when:** two-client integration test: flash triggers a countdown sprint start on both clients; pin-drop shares a route both can drive.
- **Must NOT:** wager/stake mechanics (design says wagerless).
- **Anchor:** signal table in SIGNAL_CHALLENGES.md (all five signals live or explicitly deferred).

### M16 — Live Lobbies & Async Ghosts
Live lobby racing + downloadable ghost laps + online leaderboards.
- **Done when:** two players finish the same Cleveland loop and both see corrected final standings; ghost download→playback verified headlessly.
- **Must NOT:** leaderboard writes without server validation of race hash.
- **Anchor:** leaderboard schema from GAMEPLAY_DESIGN.md extended with race-hash field.

### M17 — Hot Pursuit
Cop-vs-Runner mode: pursuit rules, busted/escape conditions, pursuit HUD.
- **Done when:** scripted pursuit scenario completes both win paths (bust + escape) in integration test; mode selectable from lobby.
- **Must NOT:** pursuit AI that cheats physics (same Chaos constraints as player).
- **Anchor:** pursuit rule spec (authored in M17 plan stage, owner-approved).

## Phase V — Product

### M18 — Cartographer Pipeline (player-facing compiler)
Universal city compiler as a product surface: request city → pipeline runs → rgpack share.
- **Done when:** a fresh city compiles end-to-end from CLI with audit PASS and loads in-game; "cartographer" achievement fires.
- **Must NOT:** ship packs that fail `citypack_audit`; silent overwrites of pinned packs.
- **Anchor:** citypack contract (CITYPACK_CONTRACT.md) + pinned source audit trail.

### M19 — Content & Certification
Akron + Cleveland polished to visual bar; all GATES rows PASS (no PROVISIONAL); perf certified.
- **Done when:** GATES.json all-PASS at branch tip; certification blockers resolved or owner-waived in writing.
- **Must NOT:** rename PROVISIONAL to PASS without evidence (grokbot gate culture is law).
- **Anchor:** GATES.json + evidence bundle index.

### M20 — Ship It
Cooked Shipping build, installer pipeline (master's a3811cb work), crash reporting, opt-in telemetry, player docs, launch checklist (GITHUB_LAUNCH_CHECKLIST / PORTFOLIO_M10_CHECKLIST).
- **Done when:** clean-machine install→launch→race→uninstall verified; crash reporter uploads a synthetic crash; docs published.
- **Must NOT:** telemetry without consent toggle; installer requiring this repo.
- **Anchor:** installer evidence + clean-machine report.
