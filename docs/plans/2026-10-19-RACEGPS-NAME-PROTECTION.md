## What it takes to lock the name (so modified versions can't keep the name)

1. **Finish clearance** (US + key markets Chris cares about; software/games Class 9, entertainment Class 41 as needed).
2. **File trademark** (US TEAS first is usual): mark **RaceGPS** (and stylized logo if wanted), owner entity (Lumen Helix Solutions or Chris’s chosen entity), specimen of use or intent-to-use. **Filing fees** are typically a few hundred USD **per class**; attorney optional but safer. **No filing until Chris says go.**
3. **Assert in the repo** (local/docs now; publish when Chris OKs): add `TRADEMARKS.md` + NOTICE language: Apache covers copyright/code; **RaceGPS** name and logo are trademarks of …; forks must rename. Apache already supports this pattern.
4. **Enforce**: cease-and-desist / GitHub trademark policy reports against impostors after registration (or sometimes with strong common-law use + notice). Registration makes enforcement much easier.
5. **Optional:** trademark the logo (neon raceGPS mark Chris locked), register domains you care about, and keep free-to-play + fun as product bars (not legal name tools).
