# raceGPS feature ideas

Living list of product ideas. **Concepts only, nothing here is built yet.**

## ZIP-code intro routing + per-city garage signs
- The intro a user sees is chosen by their **ZIP code**. A ZIP in a covered area (e.g. Cleveland-area ZIPs) gets that city's intro; an uncovered ZIP gets the intro of the **nearest biggest covered city**.
- Each city has its own 24-hour garage sign/building design: "raceGPS" fixed on top, the city name in flickering real-neon script below (Cleveland now, Akron and others later). See `../art/SIGN-TEMPLATE.md`.

## First to claim a ZIP code (the viral hook)
- Users race to be the **first** to start up raceGPS in a given ZIP code.
- The first user to show up in a ZIP gets to **create the first route** in that area.
- Ties into ZIP-code routing and the per-city garage intro signs.
- Open questions (not decided): what counts as "showing up" (GPS check-in vs. account ZIP), what the claimer is credited with (name on the route, badge), and safety/legal review of real-street routes.
